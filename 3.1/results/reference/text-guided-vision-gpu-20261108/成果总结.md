**课题3：多模态大模型价值对齐与纠正方法研究**

**（1）技术成果：面向跨模态价值一致性的文本引导条件化视觉编码方法**

**解决的问题：** 多模态大模型的视觉编码通常先于当前文本任务的交互完成，视觉表征难以根据不同道德评价维度进行调整。同一场景在关怀、公平、忠诚、权威和纯洁等维度下具有不同的关注对象，固定视觉表征可能与文本端的价值评价要求存在偏差，使模型在图像和文本分别描述同一场景时产生不一致判断。因此，研究在视觉表征形成阶段引入文本任务信息的轻量结构改造方法，并联合考察判断正确性与图文一致性，是探索跨模态价值对齐的重要技术方向。

**提出的方法与结果：** 在 MoralCLIP＋LLaVA 基础上实现文本引导条件化视觉编码结构。首先，从当前图像问题中提取 human 文本，利用冻结语言模型输入嵌入的均值表示其任务语义；由轻量条件网络生成低秩视觉残差的缩放和偏移信号，在 MoralCLIP 第 11 个编码块内部调整空间特征，再经已有投影层送入语言解码器。该结构保留 196 个空间 token、768 维视觉表示和原有多模态接口，低秩维度为 32，新增可训练参数 192,896 个。残差输出层采用零初始化，以原有模型行为作为初始状态。当前文本条件表达已知道德评价维度，不包含图像配套描述或标准答案；生成的是视觉残差调节信号，尚未涉及完整视觉编码器权重生成。

其次，采用 GPU 进行监督训练，通过原语言解码器的答案生成交叉熵向新模块反向传播，并加入视觉残差保持约束。原始视觉权重、已有投影层、语言基座和原有 LoRA 均保持冻结。训练在 A800 80GB GPU 上使用 BF16，处理 4,903 条图像问答、训练 3 轮，批量为 8，AdamW 学习率为 5×10⁻⁴。推理时保留相同的文本条件路径。结构检查、真实 7B 生成训练、保存重载以及 199 个原视觉张量的冻结核验均已完成，133 项回归检查通过。固定训练图像替换问题后，实际选用视觉特征的平均绝对差为 0.00134001，证明条件路径在实际推理精度下能够影响视觉表示。

实验采用固定 SMID 测试集，包含 87 个有效场景、288 对场景—道德维度判断和 576 条独立图文问答，报告五维宏平均 TICR、图像准确率和图文共同正确率。同次重跑原基线的三项指标分别为 90.20%、88.96% 和 85.74%。三轮训练后，验证集均未支持采用训练后的参数，按预先固定的规则选中 epoch 0；该主比较的三项指标分别为 90.20%、88.96% 和 85.74%。

为反映实际训练后参数的表现，另按选模锁定前固定的计划，对第 3 轮权重开展补充测试，该结果不参与模型选择。训练终轮 TICR 为 89.84%，相较同次基线下降 0.36 个百分点；图像准确率为 88.61%，下降 0.36 个百分点；图文共同正确率为 85.38%，下降 0.36 个百分点。TICR 差值的场景配对 bootstrap 95% 区间为 [-5.13, +3.51] 个百分点。本次完成了结构改造和可复现实验，但验证集结果尚未支持将该配置视为有效改进。测试集此前已用于历史实验，上述结论限于该固定协议。

**成果相关性及支撑作用：** 该成果面向课题三跨模态价值一致性与偏差纠正研究，提供了在视觉编码阶段注入文本任务条件的具体实现，以及从冻结基线、参数训练、验证选模到完整生成评测的实验链路。通过联合报告 TICR、图像准确率及图文共同正确率，区分结构可运行与评测效果改善，为后续研究场景语义条件、训练目标与视觉调节强度对价值判断一致性的影响提供实测依据。本阶段形成的方法实现和负面实验结果可支撑后续结构优化与消融研究，尚不作为已实现性能提升的结论。
