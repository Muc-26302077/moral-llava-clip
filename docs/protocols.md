# 模型结构、训练与评测协议

[完整流程](workflow.md) · [结果简报](results.md)

## MoralCLIP 与 R@1

公开模型为 `anaaa2/moralclip-base`，revision `1e337922befebde3f0cadb5749f37ae9521a0751`，完整权重 SHA-256：`4ace10e40a63343dc270afe776a0cc851d28dc36fd13417de07dccb12e4bac2a`。直接使用已有权重，本项目不宣称复现其从头训练。

测试126张图像、每图10条描述，共1,260条文本。图像、文本编码后分别 L2 归一化，以余弦相似度排序。项目正式 R@1 定义为首位结果与查询场景共享至少一个原始道德标签，两个方向分别统计；保留本图对应描述，包含 non-moral 标签。它不等同于严格同图配对 Recall@1。脚本同时输出配对检索和排除本图描述的诊断，不用它们替代主指标。超过77个 token 的文本按 CLIP 上限截断；最终实测44条。

## MoralCLIP–LLaVA 基线

语言基座为 `llava-hf/llava-1.5-7b-hf`，revision `b234b804b114d9e37bb655e11cbbb5f5e971b7a9`。将原视觉塔替换为真实 MoralCLIP ViT-B/16，严格核对全部视觉张量。输入224×224图像，取 `hidden_states[-2]` 并去掉 CLS，得到196×768的空间特征。新投影器为 `Linear(768,4096) → GELU → Linear(4096,4096)`。CLIP 文本编码器与全局检索投影不进入生成路径。

| 阶段 | 监督样本 | 更新部分 | 轮次 | 学习率 |
| --- | --- | --- | ---: | --- |
| 投影器适配 | 4,903条图像问答 | 投影器 | 1 | 1e-3 |
| 图文极性微调 | 9,806条独立图像／文本问答 | 投影器、语言 LoRA | 3 | 投影器1e-4；LoRA 2e-5 |

两阶段均冻结原始视觉塔和语言基座。原设置为 BF16、batch 8、梯度累积1、seed 42、cosine schedule、warmup 0.03、weight decay 0；LoRA rank 16、alpha 32、dropout 0.05。只监督答案及 EOS，问题、图像 token、padding 的 label 为−100。分别按验证答案损失选择权重，测试集不参与选模。第二阶段选中第1轮权重，随 adapter 保存完整投影器。

## 文本引导视觉编码

将图像任务的 human 问题通过冻结语言输入嵌入取均值，得到4,096维条件 q。条件网络生成32维低秩空间的缩放和偏移，在 MoralCLIP 第11个编码块（index 10）内部调节空间特征，CLS 不变：

```text
h' = h + 0.1 × Up(GELU((1 + tanh(gamma(q))) × Down(LN(h)) + tanh(beta(q))))
```

新增192,896参数，Up 零初始化；初始模型与基线完全一致。条件仅来自问题，不读取标准答案、配套 caption 或生成场景解释。训练与预测均保留此路径；该实现生成视觉调节信号，不生成整套编码器权重。

新增参数以 FP32 保存，主模型 BF16。冻结视觉原权重、投影器、语言基座和既有 LoRA，只训练新增残差。使用4,903条图像问答，3轮、AdamW、学习率5e-4、batch 8、seed 42；损失为逐问答答案／EOS生成交叉熵，加0.05倍归一化视觉残差保持约束。当前未直接优化图文一致性损失。

每轮在完整580条验证问答上评测；图像准确率和合法输出率不低于基线才有选模资格，再按共同正确率、图像 BA、TICR 选优，同分保留更早轮次。第0轮参与候选。当前验证所选为第0轮；实际训练第3轮另作固定终轮补充评测，不能将零残差的相同成绩归为训练增益。

## SMID 极性 TICR 与准确率

原项目划分为训练2,140、验证134、测试126图；公开副本按既有版权记录排除两张训练图，保留2,138张。极性任务只纳入在相应道德维度已有正／负标注的场景，不把未标注视为负例或道德中性。

| 划分 | 有效场景 | 场景—维度对 | 独立图像／文本问答 |
| --- | ---: | ---: | ---: |
| train | 1,381 | 4,903 | 9,806 |
| validation | 79 | 290 | 580 |
| test | 87 | 288 | 576 |

五维依次为关怀／伤害、公平／欺骗、忠诚／背叛、权威／颠覆、纯洁／污秽；测试分母为72、42、63、55、56对。原测试 A/B 各63场景，极性筛选后为43／44场景。`data/groups.json` 保存固定分组。

图像路只输入图片与问题；文本路只输入固定 caption 0 与问题。提示已知目标道德维度，任务是判断该维度正负，不是让模型自行发现全部道德维度。文本描述继承图像标签，未逐条重新标注语义等价性。

自由贪心生成，最多16个新 token；严格接受该维度的完整中文极性标签，忽略两端空白，不从解释段落提取答案。无效回答留在分母，两个无效回答不算一致。TICR 为每维图像与文本合法答案一致率的五维等权平均；两路都答错仍可一致，因此同时报告两路准确率、BA、共同正确率和合法输出率。micro TICR 另行报告，不替代宏平均。

原历史基线使用推理 batch 8，创新模块及其直接基线使用 batch 1。相同权重的两次基线有两条原始回答变化，历史 TICR 90.21%、同次重跑90.20%；新增模块的配对效果使用同次基线，原因未通过专项消融隔离。

三个公开模型不使用本项目训练集微调，按各自原生预处理和模板推理。中文格式符合程度会影响主结果；VLGuard Posthoc 额外容许标签后的单个句号时，诊断 TICR 为48.86%，正式严格成绩仍为41.08%。

差值不确定性按场景配对 bootstrap 2,000次、seed 42，五维分母分别重算。测试集已用于历史实验，不属于新盲测；上游 MoralCLIP 与公开模型的训练集重合未全面审计。历史存在性、三状态任务的指标不能与当前极性 TICR 混用。

## MORALISE

MORALISE 为独立评测基准：[论文](https://arxiv.org/html/2505.14728)、[作者数据](https://huggingface.co/datasets/Ze1025/MORALISE)，revision `80ed627e8f12c2e8ab8839f5639d56d4625b4127`。按作者英文提示使用图片与原文本联合输入，自由贪心生成，最多64个新 token，不计算图像与文字分路 TICR。

S1道德判断共2,481题；S2单规范选择、S3多规范识别各2,480题，原始一条缺失规范标签的场景仅保留在S1。S1／S2按13个来源类别等权平均，S2选中任一金标准规范即命中；S3为13个规范的宏 F1。严格解析完整选项字母和有限括号／分隔符，不从解释中抽字母；无效输出保留在分母。不宣称这些分数复现论文所发表数值。

MORALISE 未用于本项目训练和选模。目前仅图文微调基线完成该评测，残差创新结构没有该项实测成绩。
