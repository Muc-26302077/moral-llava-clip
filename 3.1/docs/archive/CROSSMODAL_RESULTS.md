本文保留旧图像 LoRA 的首轮成对评测结果（A/B 均 57.14%）。后续图文联合训练已完成，固定组 A 达 68.25%、B 达 60.32%；准确率存在取舍，详见 [最新完整总结](CROSSMODAL_IMPROVEMENT_RESULTS.md)。

原始 LLaVA 与已有图像标签 LoRA 在同一运行环境重新推理；未训练、未更改权重。

A/B 为原始 SMID 测试划分的两个不重叠子组，每组 63 张，固定使用 captions[0]。它们不是两个外部独立数据集。

主分析在推理前固定为 constrained：两个模型均使用同一 243 种合法 JSON 答案约束，主指标为五维完整一致率；free 为单独的补充诊断。

门槛：每组主指标 >=60%，即至少 38/63。无效输出计失败；不修补回答、不根据结果改组。

## 一致与正确的区分

已核查原始基模在 constrained 下的 **252/252 条回答全部为全 not_annotated、non_moral=true**。其 100% 一致率来自恒定输出，不能解释为基模道德判断优于 LoRA。该格式控制协议为基模产生了退化预测，后续应在验证集上设计更有区分度的标签判断协议，再锁定新协议测试。

常量模型在两种输入下始终输出全 not_annotated，可取得 100% 跨模态一致率；因此一致率本身不证明道德判断准确或视觉信息被有效利用。

## 验证与限制

- 四个预测文件各 252 条，总计 1008 条；ID/模态唯一并完整覆盖两个固定组。
- 从 raw_prediction 独立重算两种协议，结果与运行器保存指标逐项相符；文件哈希保存在 verification.json。
- 新增 8 项评分/分组回归测试、原有 11 项评分测试全部通过；GPU 小样本覆盖两个模型、两种模态和两种解码。
- 生成 caption 的语义等价性尚待人工审核，图片级标签不能自动视为独立人工文本道德标注。
- 当前为固定单划分、单次解码协议的探索性结果；未证明外部泛化或达到原 95% 目标。
- not_annotated 表示数据未标注，不代表已确认中性。

## 逐条错误诊断

LoRA 两种解码得到的 252 条结构化判断完全一致。126 个场景中：54 个两边都正确，18 个两边相同但错误，16 个仅图像正确，13 个仅文本正确，25 个两边不同且都错。54 个不一致场景已完整保存至 runs/crossmodal-v1/disagreement_examples.json。

630 个维度对比中有 149 处不一致：136 处为 not_annotated 与已标注极性之间的差异，13 处为 virtue/vice 翻转。修复重点应包含标签有无及描述信息保留，不能只针对正负极性。逐维统计见 runs/crossmodal-v1/diagnostics.json。
