**课题3：多模态大模型价值对齐与纠正方法研究**

**（1）技术成果：面向跨模态价值一致性的文本引导条件化视觉编码方法**

**解决的问题：** 多模态模型通常在图文融合之前独立完成视觉编码，视觉表征缺乏对当前文本评价要求的感知，可能造成视觉证据与文本价值判断依据之间的偏差。本研究面向已知道德维度条件下的图文价值判断，将任务问题中的文本语义引入视觉编码，探索从表征形成阶段改善跨模态价值一致性。

**提出的方法与结果：** 已实现文本引导的条件化视觉编码结构，在 MoralCLIP 第 11 个视觉编码块内部加入低秩残差模块。利用冻结 LLaVA 的输入嵌入表示当前问题文本，由轻量条件网络生成视觉特征调节的缩放与偏移信号，影响空间特征的形成。该条件路径同时用于训练与推理；不读取图像配套描述或标准答案。当前版本的文本条件表达任务评价维度，尚不包含由图像自动生成的场景解释。新增可训练参数为 192,896，原始视觉权重、投影层、语言基座及已有 LoRA 保持冻结，输出层零初始化以保留原基线行为。

GPU 训练采用原语言解码器的标签与 EOS 生成交叉熵，通过冻结解码器反向传播至新视觉模块，并加入视觉残差保持约束。CPU 负责样本处理及监督信号组织。该 GPU 训练流程已编写，端到端运行与正式指标仍等待 CUDA 设备可用后验证。

已完成 CPU 结构检查与真实图像小样本诊断。在从原始训练集和验证集固定抽取的 20 条训练与 10 条验证图像问答上，冻结视觉特征及文本引导残差两种设置的线性探针验证准确率均为 60.00%，验证交叉熵分别为 1.056738 和 1.119727，未观察到泛化改善。同一图像替换问题文本后，视觉特征平均绝对差异约为 0.0012207，表明条件路径能够影响视觉表征。该诊断没有运行 7B 语言解码器，其结果不能作为 LLaVA 准确率或 TICR。原已完成 MoralCLIP＋LLaVA 基线的 TICR、图像准确率、文本准确率及共同正确率分别为 90.21%、88.97%、92.32% 和 85.75%；新结构对应指标待 GPU 正式评测后填入。

**成果相关性及支撑作用：** 该实现为课题三跨模态价值一致性与偏差纠正研究提供了可训练的视觉编码结构改造方案。后续在相同输入与生成协议下联合比较 TICR、图像判断准确率及图文共同正确率，并按场景开展配对不确定性分析，以检验模型结构改变是否带来可靠的价值一致性改善。方法在更广泛场景文本条件及未知分布上的适用性仍需评估。
