# 可靠文本指导图片：条件蒸馏实验方案

日期：2026-11-02（Asia/Shanghai）。状态：**方案与配置已落盘，改动前备份已建立；新预测头、训练器及正式训练尚未实施。**

## 1. 目标、资源及验收

只使用已有 SMID 数据与固定 revision 的 LLaVA-1.5-7B；不新增标注、不调用外部教师、不更换基模，正式训练最多 3 组。两路共享同一个语言解码器、同一个语言 LoRA 和同一个五维标签预测头，独立输入、独立推理。

| 指标（固定 126 场景、caption 0） | 最新联合 LoRA | 本轮验收 |
| --- | ---: | ---: |
| 图像、文本五维共同完整正确 | 53/126（42.06%） | >=101/126（80.16%） |
| 两路五维完整一致 | 81/126（64.29%） | >=114/126（90.48%） |
| 图像五维完整正确 | 69/126（54.76%） | >=101/126，由共同正确条件同时保证 |
| 文本五维完整正确 | 63/126（50.00%） | >=101/126，由共同正确条件同时保证 |

验收采用整体点估计，另报原 A/B 各 63 场景的结果及 Wilson 95% 区间；不要求每个子组也达到 80%/90%，不把逐维准确率或 F1 当作五维完整正确率。两项主条件必须同时成立。

目标是实验要检验的要求，不是训练后的性能承诺。当前测试已经被查看，不能称为新的独立盲测。生成描述继承图片标签，不保证语义等价；本轮无法通过自动置信度补齐人工语义审核。

## 2. 为什么替换原一致性约束

原方案通过对称 JS 让两路概率接近，无法区分谁对谁错；一致但错误场景从 18 增至 28。目前文本完整正确率还低于图像，因此不适合无条件要求图片跟随文本。

新思路是：图片与文字始终对照真实标签学习；仅当训练中文字在某维度答对、且真值概率足够高时，该维度才额外指导图片。图像错误但文本正确的维度是重点受益对象；图像已正确时也允许弱指导，不增加新的学生筛选条件。

这属于共享参数模型的在线自蒸馏，不是额外加载一个更强或固定的教师。stop-gradient 只阻断当前蒸馏项沿教师输出回传的梯度；图片更新仍会改变共享解码器和预测头，从而影响后续文字输出，不能声称教师参数始终不变。

## 3. 共同结构与标签监督

图片：原视觉塔 -> 原多模态投影器 -> 图像特征进入语言 decoder。

文字：原描述和任务问题 -> tokenizer/embedding -> 同一个语言 decoder；没有像素或 image token。

复用现有 image_prompt()/text_prompt() 的完整输入提示，不拼接答案。从最后一个有效提示 token 的最后层隐藏状态提取特征；使用 LayerNorm(hidden_size)、Dropout(0.1)、Linear(hidden_size, 15)，重排成 [B, 5, 3]。隐藏维度从基模配置读取，不写死 4096。特征提取接口只返回最后层所需特征，避免不必要的完整词表 logits。

五维和三状态顺序分别沿用 FOUNDATION_KEYS、STATES；两路共享一个预测头。每维 argmax 后确定性转成原六字段 JSON，non_moral 由五维状态派生。它是分类预测，不是原生生成 JSON；其格式有效率不能解释为自由生成能力。

输入不包含标准答案、先前维度的真实状态或另一条路的预测。原生成式代码和历史记录保留，新增独立实验入口及 checkpoint 格式；不把分类头输出冒充旧 constrained/free 协议。

每维类别权重只从 train 原始标签计算：

    u[d,c] = clip(sqrt(N / (3 * max(n[d,c], 1))), 0.5, 2.0)
    w[d,c] = u[d,c] / mean_c(u[d,c])
    CE_m = mean_(b,d)(w[d,y] * -log p_m[b,d,y])
    L_supervised = 0.5 * (CE_image + CE_text)

上式按元素数量平均，不依赖框架加权 CE 的隐式分母。先做 float32 log_softmax 计算损失。三个实验采用相同权重、采样、模型初始化及训练预算。

## 4. 条件蒸馏的精确定义

每个 batch 内进行一次额外纯文本教师前向：暂时将共享模型置为 eval，在 no_grad 下取得 p_teacher，再恢复原训练模式。教师不启用 dropout，也不读取真实标签作为输入；真实标签仅用于训练损失和门控判定。

    gate[b,d] = (argmax(p_teacher[b,d]) == y[b,d])
                AND (p_teacher[b,d,y[b,d]] >= 0.70)

    KL[b,d] = sum_c p_teacher[b,d,c]
              * (log p_teacher[b,d,c] - log p_image[b,d,c])

    L_KD = sum(gate * KL) / max(sum(gate), 1)
    L = L_supervised + lambda(epoch, step) * L_KD

教师概率完全 detach，门控不求导；概率取 float32 并做数值下界保护。没有合格维度时蒸馏为带学生图的零值，不产生 NaN。温度 T=1，门槛不按测试结果调整。

图像与文字的真实标签监督都持续开启。教师的 eval 前向只参与蒸馏目标；文字监督使用单独的 train 前向，保留自己的梯度。推理时关闭整个教师/门控路径；图片输入不依赖配对描述、真值或其他场景。

## 5. 三组正式实验

| 组 | 附加损失 | 目的 |
| --- | --- | --- |
| A_supervised | 无 | 验证共享预测头及两路监督的正确性基础 |
| B_symmetric_js | 两路 train 概率的对称 JS | 同架构的一致性对照，量化共同错误变化 |
| C_conditional_kd | 上述可靠文本 -> 图片 KL | 检验方向性、可靠性门控及弱指导的组合效果 |

三组均从 runs/moral-llava-1.5 初始化同一个语言 LoRA；相同 seed 初始化预测头并核对初始权重哈希。**不从最新 JS 模型继续训练**。三组均冻结视觉塔、原投影器、语言基础权重；本轮取消原先第三组视觉投影器微调，避免在仅 3 组预算内混入额外结构变量。

固定配置：seed 42、BF16、pair batch 4、梯度累积 1、10 epochs、每轮 535 steps，共 5350 steps/组。最后不足 4 场景的 batch 保留，不 drop_last。

- 第 1 轮仅训练预测头；第 2 轮开启语言 LoRA，rank/alpha/dropout 继承旧 adapter。
- head LR=1e-4，LoRA LR=2e-5；AdamW，weight_decay=0.01，grad_clip=1。
- 每组参数从启用时起独立执行其剩余训练步数的 5% 线性 warmup，然后 cosine 衰减。LoRA 开启前不创建该组优化器状态、不执行 weight decay。
- A 的附加损失权重始终为 0。B/C 第 1-2 轮为 0，第 3 轮第一步至第 4 轮末从 0 线性升至 0.05，第 5-10 轮为 0.05。
- 每场景每轮一条描述，caption index=(epoch-1)%10，十轮覆盖全部十条；场景等权。每轮 shuffle 使用 seed+epoch，三个实验顺序相同。
- 输出目录固定为 runs/conditional-distillation-v1/{A_supervised,B_symmetric_js,C_conditional_kd}；已存在时拒绝启动，只有显式恢复命令允许接续原实验。

B/C 的损失不同，数值权重相同不代表约束强度相同。日志必须记录加权附加项与监督项的比例；本轮只能比较整套策略，不能单独归因于方向、门控或损失形式，也不能单独归因于预测头结构。

## 6. 验证、选模与最终测试

训练代码只读取 train/validation 清单及对应处理文件，校验 ID、图片哈希、标签一致性。测试文件不得被训练器、采样器、门控或阈值选择访问。

训练前，用旧图像 LoRA 及最新联合 LoRA 重算 validation 的 caption 0 和全部十描述指标，作为保留基线；不重新训练它们。记录精确源码/输入/权重哈希。

每轮验证 134 场景：图片每场景预测一次，十条文字分别预测；每场景先对十个图文对取平均，再跨场景平均。图片准确率按场景计一次。另报固定 caption 0 指标，所有验证预测均落盘。eval、无门控、无真值输入、无跨路概率融合。

候选门槛：验证图像完整正确率、十描述文本完整正确率均不得低于旧图像 LoRA 的同口径基线；不能只约束两路平均值。合格候选按以下元组降序选取：

    (十描述场景平均共同正确率,
     min(图像完整正确率, 十描述文本完整正确率),
     十描述场景平均完整一致率)

完全并列取更早轮次；跨实验并列取 A、B、C 顺序。若无合格候选，记录无新模型可替换，保留历史部署权重。即使 A/B 结果较差也继续预设 C；除数值、数据、磁盘或 GPU 故障外，不按中间结果改配置或增加实验。

三个实验结束、全局选择文件锁定后，仅最终选中的新权重执行一次正式测试：原 126 场景、A/B 分组、caption 0 不变；十描述全量结果作为补充，不用于重新选模。历史两模型沿用既有 caption 0 原始预测。

报告完整覆盖的共同正确率、两路准确率、一致率、共同错误数量、逐维混淆、11 标签 micro/macro-F1、Wilson 区间。十描述相关样本按场景聚合，不能把 1260 对作为独立样本构造狭窄区间。非法/缺失输出不得删除以提高分数；重复或 ID 覆盖缺失直接判评测失败。

共同正确>=101 且完整一致>=114 才通过；否则明确未达标，不换描述、不删样本、不改标签、不追加测试集驱动调参。本轮单 seed 的结果不构成多种子稳健性证明。

## 7. 必须保存的诊断与恢复状态

逐步日志：两路监督损失、JS/KD 原始值和加权值、门控比例、按维度/状态门控覆盖、教师在 batch 上的准确率、文本正确但图片错误的维度数、学习率、梯度范数、显存、耗时。区分“高置信但错误被拦截”和“正确且合格”的教师维度。

每轮保存验证逐条预测及输出标签组合分布，防止向全 not_annotated 收缩。报告“新增共同正确、失去共同正确、新增共同错误”，不以一致率上涨代替正确率改善。

实施时的完整恢复 checkpoint 必须包含：LoRA、预测头、optimizer、各参数组 scheduler、epoch/step、batch cursor、确定性采样状态、Python/Torch/CUDA RNG、配置/数据/源码/基模哈希；每 100 步及轮末原子保存。保留最近完整恢复点及最佳权重，其他轮次保留配置和预测，控制磁盘占用。恢复先校验配置及哈希，不兼容则拒绝接续；更换 CUDA/依赖环境不声称 bit-exact。

新增入口在实现后提供：训练单组、resume 单组、仅独立预测、评测及校验。当前 JSON 为设计配置，不是已实现 CLI 的可运行参数，不提供会误启动旧训练器的命令。

## 8. 实施前检查与测试规范

1. CPU 数值：门槛边界、错误教师高置信被拒绝、正确教师低置信被拒绝、局部门控、零门控、相同分布 KL=0、非有限输入拒绝、KL 温度与方向。
2. 梯度：单独 KD 对图像 logits 有梯度、教师 logits 无梯度；两路 CE 都有梯度；共享参数受到图片更新的事实单独说明。
3. 模型：相同隐藏维度的两路共用头；不同隐藏维度的小随机模型可适配；图片有视觉特征、文本无像素；最后有效位置不受 padding 影响。
4. 泄漏：改变目标标签不改变输入或无门控推理结果；移除配对描述不影响图片独立预测；相同样本单独/混批结果一致。
5. 训练恢复：小模型连续 N 步与中断后恢复至 N 步一致；旧权重哈希不变；保存/重载概率一致；目标目录已存在时拒绝覆盖。
6. 评测：全部 ID/模态/描述覆盖；门槛 101 和 114 的边界；两条同样错误结果不能计共同正确；十描述按场景计权；缺失/重复预测拒绝评分。
7. GPU：重新探测 CUDA/BF16，验证冻结策略与有限梯度，完成 2 步训练、完整保存/重载及两路独立预测，再串行执行三组正式实验。
