**课题3：多模态大模型价值对齐与纠正方法研究**

**（1）技术成果：面向跨模态价值一致性的文本引导道德视觉编码方法**

**解决的问题：** 在多模态大模型的价值判断过程中，图像与文本对同一场景的描述具有不同的表达形式，容易出现单一模态判断较为准确、图文价值判断却不一致的问题。通用视觉编码器主要学习物体、动作和场景等语义特征，对关怀、公平、忠诚、权威和纯洁等道德维度的关注不足；同时，视觉表征通常在与当前问题充分交互之前形成，难以根据不同道德评价任务调整特征。同一图像在不同道德维度下需要关注的对象和关系也不相同，固定视觉编码难以充分表达这种任务差异。此外，仅依靠投影层完成视觉特征与语言空间的适配，不能充分协调图像端与文本端的价值判断。因此，如何结合道德视觉先验、图文价值监督和文本任务指导，在控制新增训练参数规模的同时实现可调节的视觉编码，是跨模态价值对齐与偏差纠正需要研究的问题。

**提出的方法与结果：** 针对上述问题，提出并实现了一种面向跨模态价值一致性的文本引导道德视觉编码方法，将 MoralCLIP 道德视觉先验、图文极性监督训练和文本条件化视觉残差统一纳入 MoralCLIP＋LLaVA 框架。

首先，构建道德视觉先验驱动的跨模态表征适配机制。以 MoralCLIP 作为视觉编码器，通过适配投影层将道德相关的视觉特征映射至 LLaVA 语言空间，在保留原始视觉权重的基础上完成多模态接入。采用图像问答与文本问答的共同道德极性目标训练投影层和语言 LoRA，使模型分别处理图像与文字描述时学习相同的评价标准，缓解仅完成视觉投影适配时图文两路判断能力不均衡的问题。

其次，设计文本条件生成的低秩视觉调节机制。利用冻结语言模型的输入嵌入表示当前问题，由轻量条件网络生成低秩空间特征的缩放与偏移信号，并在 MoralCLIP 选用的视觉编码层内部施加条件残差，使视觉表示能够随道德评价问题调整。该模块新增 192,896 个可训练参数，采用零初始化残差输出，在训练与预测阶段保留相同的文本指导路径。当前条件来自问题本身，表达已知的道德评价维度，不包含配套描述或标准答案；文本生成的是视觉残差调节信号，而非完整编码器权重。

最后，建立分阶段监督训练与联合评测机制。依次完成投影层适配、图文极性监督训练和条件视觉模块训练；在条件模块训练阶段冻结已有视觉权重、投影层、语言基座及 LoRA，采用 GPU 通过答案生成交叉熵监督新模块，并加入视觉残差保持约束。评测联合考察图文一致率 TICR、两路准确率及图文共同正确率，避免仅凭一致率判断对齐效果。

实验在固定 SMID 测试集上开展，包含 87 个有效场景、288 对场景—道德维度判断和 576 条独立图文问答，覆盖五个道德维度，指标采用五维宏平均。以仅完成投影层适配的 MoralCLIP＋LLaVA（projector_only）作为基础阶段基线，完整方案第 3 轮参数的补充评测 TICR 为 89.84%，较基础基线的 74.37% 提高 15.47 个百分点；文本准确率由 70.63% 提高至 92.32%，提高 21.69 个百分点；图文共同正确率由 67.81% 提高至 85.38%，提高 17.58 个百分点；图像准确率由 90.61% 降至 88.61%，下降 2.00 个百分点。上述阶段性对照反映完整训练流程的综合变化，改善主要体现在文本判断和图文一致性方面，不能将其全部归因于新增条件模块。

进一步以已完成图文监督训练、未启用条件残差的模型作为直接对照，同次重跑基线 TICR 为 90.20%，实际训练终轮为 89.84%，下降 0.36 个百分点；差值的场景配对 bootstrap 95% 区间为 [-5.13, +3.51] 个百分点。三轮验证均未支持采用训练后的条件参数，按既定选模规则保留 epoch 0，其测试表现与直接基线一致。固定图像更换问题后，实际视觉特征的平均绝对差为 0.00134001，说明文本条件能够影响视觉表示，但当前实验尚未证明该模块具有独立的性能增益。该测试集此前已用于历史实验，上述结论限于该固定评测协议。

**成果相关性及支撑作用：** 该成果与课题三“多模态大模型价值对齐与纠正方法研究”中道德相关表征学习、跨模态价值一致性评估及结构层偏差纠正等研究内容相关。通过将道德视觉先验、图文共同评价目标和问题文本指导引入同一模型，形成从视觉特征接入、价值监督训练到条件化视觉调节的实现路径，为研究文本信息如何参与视觉价值表征提供技术基础。通过同时报告 TICR、两路准确率及图文共同正确率，并保留基础阶段与直接对照结果，为区分完整流程收益和单一模块效果提供实测依据，可支撑后续场景语义条件、显式图文一致性目标及视觉调节强度的消融研究。本阶段已完成方法实现与实验验证，新增条件模块的效果仍需进一步优化。
