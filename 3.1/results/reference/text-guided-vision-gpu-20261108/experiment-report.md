# 文本条件化视觉编码：GPU 实测结果

本次测试包含 87 个有效场景、288 对图文判断、576 条问答，按五个道德维度宏平均。固定测试集此前已用于历史实验，不能作为新盲测。所有对比采用 BF16、batch 1、自由贪心生成、最多 16 个新 token。

验证集选中 epoch 0。epoch 0 为零初始化残差，保持原模型行为；验证选中结果与训练终轮结果分别列出。固定终轮补充计划在选模锁定之前提交，补充结果不改变选模结论。

历史原基线 TICR 为 90.21%，本次同环境重跑为 90.20%，宏平均差 -0.006494 个百分点，逐条比较有 2 条回答变化。基线权重与原始 MoralCLIP 哈希核验通过；这里采用本次重跑作配对对照。变化原因未通过专项消融隔离，不归因于训练。
