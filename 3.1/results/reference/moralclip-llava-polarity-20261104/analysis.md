# 原始 MoralCLIP 接入基线：结果分析

真实 MoralCLIP 视觉塔、投影层适配和极性问答联合训练已完成；本报告对应保存并重载的最终基线，不使用历史原 LLaVA 视觉塔结果代替。

## 结果与变化

| 阶段 | 图像准确率（五维宏平均） | 文本准确率（五维宏平均） | TICR（五维宏平均） | 共同正确率（五维宏平均） |
|---|---:|---:|---:|---:|
| projector_only | 90.61% | 70.63% | 74.37% | 67.81% |
| trained | 88.97% | 92.32% | 90.21% | 85.75% |

联合训练后，TICR 提高 15.83 个百分点，文本准确率提高 21.69 个百分点；图像准确率下降 1.64 个百分点。结果表明本次训练主要改善文本端与跨模态一致性，不能描述为所有指标均提升。
图像/文本宏平均 balanced accuracy 分别为 87.61%/91.23%。A/B 两组 TICR 分别为 88.08%/92.12%；达到各组 ≥60% 及两路 BA >50% 的既定条件。

## 训练与选模

投影器适配完成 613 步；联合训练完整完成 3678 步。两阶段的验证集合不同，不能直接把两阶段验证 loss 数值之差作为改进幅度。联合阶段验证结果如下：

| epoch | 优化步 | 验证答案 loss |
|---:|---:|---:|
| 1 | 1226 | 0.03843847 |
| 2 | 2452 | 0.05399566 |

验证集选中 checkpoint-1226（第 1 轮）；第 2、3 轮未进一步改善验证 loss，最终恢复第 1 轮的投影器和语言 LoRA 后才执行测试。保存权重与该 checkpoint 的 SHA-256 一致。

## 接入与独立复现证据

- 视觉塔来自用户确认的原始 MoralCLIP；完整来源权重哈希固定。199 个视觉张量在加载时严格匹配，两个正式训练阶段结束后再次逐张量核验，视觉塔未被更新。
- 实际输入为 224×224、196 个 patch token、768 维视觉特征；新投影器为 768→4096→4096。语言基座冻结，联合阶段只训练投影器与语言 LoRA。
- 图像端不读取配套描述；文本端不输入图像。两路自由贪心生成，参考答案不进入推理输入。
- GPU 两阶段 smoke、混合模态保存重载通过；110 项测试通过。第一轮 checkpoint 实际包含 448 个 LoRA 张量及 4 个投影器张量，二者均发生训练更新。
- 从 GitHub 独立检出的提交 4c62f86 再次准备数据、运行完整 576 条推理和评分，所有原始回答及全部指标与本次正式输出完全一致。复现使用固定外部基模与新训练 adapter；公开模型已通过 Git LFS 上传，独立抓取远端提交后，LFS 指针的 SHA-256 和文件大小均与选中模型一致；未完成远端二进制重新下载测试，不能将该记录表述为从远端重新下载全部模型后复现。
- 启动时 HEAD 仍为父提交 d885a16；冻结文件记录了所有实际执行源码的 SHA-256，这些源码与之后发布的实现提交 4c62f86 完全一致。

## 解释范围

本基线证明真实 MoralCLIP 已接入并完成极性问答流程；尚未进行视觉塔微调或生成文本反馈视觉编码。历史原 LLaVA 视觉塔的 TICR 91.36%、图像/文本准确率 93.95%/92.32% 来自不同 adapter 初始化及训练阶段，不能将两个运行的差异单独归因于视觉塔。
固定测试集此前已用于历史实验，不能称为全新盲测；上游 MoralCLIP 训练数据与本测试集重叠尚未核实。文本描述继承源场景标签。本报告不证明未知数据分布上的准确率保证。
原始 MoralCLIP 双向 R@1 仍是独立的道德标签检索基准，图到文 100.00%、文到图 93.33%；本次没有将 LLaVA 极性判断结果当作 R@1。
