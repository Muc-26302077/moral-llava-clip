# 结果分析与解释边界

可核验的观测：

- 正式训练只有 5 种不同图像问题模板，对应五个道德维度；同一维度不同场景采用相同问题条件。当前条件包含任务信息，缺少场景专属的文本语义。
- 三轮验证均未通过原基线图像准确率守卫，最终选择 epoch 0。主评测反映该选模策略；epoch 3 补充反映实际训练后参数。
- 终轮在固定测试集有 13 条图像回答与基线不同，其中正确→错误 7 条，错误→正确 6 条。逐条记录见 changed-image-answers.json。
- 同一训练图像替换为另一维度的问题后，选用视觉特征的平均绝对差为 0.00134001183，最大差为 0.03125，变化元素比例为 63.6626%。这验证了实际 BF16 推理时的条件依赖，不说明判断更准确。
- 当前目标为图像答案生成 CE＋0.05 倍视觉残差保持项，未直接加入图文预测一致性约束。每轮生成 CE 的分布见 training-loss-summary.json；它不能替代 TICR。

可能原因与下一步假设：任务模板条件不能区分同一道德维度下的不同场景；在已有 SFT 基线之上继续用相同答案监督小残差，可能对少量训练难例过度调整；单模态答案损失与跨模态一致性目标也存在差异。这些解释有上述观测支持，但尚未进行逐项因果消融。后续可在验证集上比较更丰富、无答案泄漏的场景条件、降低更新强度或显式一致性损失，当前不将这些待做方案写成已完成成果。

本实验不构成 MORALISE 原生任务分数，也未测量 R@1。结论限于本次固定 SMID TICR 协议。
