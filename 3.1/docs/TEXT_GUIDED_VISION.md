# 文本引导条件化视觉编码：实现与实验入口

新分支：`codex/text-guided-vision-20261108`。原始 MoralCLIP＋LLaVA 基线保持独立。

## 已实现的结构

文本条件来自当前图像任务的 human 问题，使用冻结 LLaVA 输入嵌入均值表示。
条件网络生成低秩空间特征的缩放与偏移信号，在 MoralCLIP 第 11 个编码块的输出内部施加残差。
该位置对应现有 `hidden_states[-2]`，保留 196 个空间 token 与 768 维特征，CLS 不加残差。
随后继续使用原有投影层和语言解码器。推理时同样保留文本条件，条件网络不读取标准答案或配套描述。

`h' = h + 0.1 × Up(GELU((1+tanh(gamma(q))) × Down(LN(h)) + tanh(beta(q))))`。

低秩维度 32，可训练参数 **192,896**；输出层零初始化，初始行为与基线一致。
原始视觉权重、已有投影层、语言基座及原有 LoRA 全部冻结。新模块使用 FP32 参数，主模型使用 BF16。
这是“问题文本条件化视觉编码”实现：文本表达已知道德维度，尚不表达由图像自动生成的场景解释。
不能将当前版本描述为已实现完整编码器权重生成或场景文本反馈推理。

## CPU 检查与真实图像诊断

结构检查覆盖实际微型 LLaVA 的混合图文前向、生成、生成损失反传、文本条件依赖、文本分支不变、保存重载及泄漏防护。
微型随机模型仅验证代码路径，不评估研究效果。

真实图像诊断从原始 train/validation 按维度和正负类固定抽取 20/10 条图像问答，涉及 30 张独立图像。
使用原始 MoralCLIP 冻结特征与同一任务专属冻结线性探针；该诊断不运行 7B 解码器，不输出 TICR。
在 2 GiB 容器限制下，全量 FP32 与 BF16 塔加载尝试被终止；最终采用逐算子内存映射的 NumPy FP32 提取。
其编码层计算及图像预处理已与 Transformers 微型 CLIP 进行数值一致性检查。

已完成诊断：基线/新模块的验证准确率均为 **60%**，验证交叉熵 **1.056738→1.119727**，未观察到泛化改善。
训练准确率均为 100%；同一图像替换问题后的平均特征差异约 **0.0012207**。
该结果证明条件路径可运行，不能据此声称新方法提升准确率或 TICR。

## GPU 训练及正式评测

启动 GPU 后，在仓库中运行：

```bash
bash 3.1/scripts/run_text_guided_gpu.sh
```

可设置 `BASE_SNAPSHOT` 指向固定 LLaVA 快照、`PYTHON_BIN` 指向环境解释器；脚本首个位置参数可指定新的运行根目录。
默认全部使用本地模型文件。建议提供至少 24 GiB 显存的 BF16 GPU，实际需求以 GPU smoke 的峰值记录为准。
当前 CPU 诊断不构成显存需求的实测依据。

执行顺序：本地资源与数据审计 → GPU 小样本生成训练与重载 → 正式训练 → 验证集选模 → 冻结测试集评测 → 结果文案回填。
GPU 不可见时训练命令立即退出，不会自动改用 CPU 加载 7B。小样本只使用 train/validation，不读取测试答案训练。

正式训练默认原有 4903 条图像问答、3 epochs、单卡 microbatch 8、梯度累积 1、AdamW LR 5e-4、seed 42。
GPU 实测后将原计划的 microbatch 1、梯度累积 8 改为直接批量 8，保持有效批大小为 8。
答案生成损失先按每条问答的有效监督 token 求均值，再按问答求均值；末尾不足批次按实际条数加权。
损失为原始解码器的标签与 EOS 生成交叉熵，加 0.05 倍归一化视觉残差保持项。
CPU 只负责数据与监督组织；GPU 通过冻结解码器反传至新编码模块，无分类探针替代。
每轮生成完整验证集 580 条回答；图像准确率和合法输出不低于同次重跑基线才有选模资格，
依次按共同正确率、图像平衡准确率、TICR 选优，同分保留更早轮次；epoch 0 也参与选择。
选模锁定后，基线与选中模型分别在同一完整测试集生成 576 条回答。文本分支回答必须完全一致。

正式 TICR 使用原有五维宏平均，保留 A/B 分组，另报图像/文本准确率、平衡准确率、共同正确率与共同错误。
对 TICR、共同正确率及图像准确率的变化按场景做配对 bootstrap（2000 次、seed 42）。
模型若没有改善，文案明确写明未取得改善；epoch 0 被选中时不会描述为训练参数带来了提升。

产物位于脚本打印的 `formal/`：

- `status.json`、`frozen_config.json`、`training-loss.json`：运行状态、源代码/数据指纹、训练曲线。
- `epoch-*`、`selection.json`：新模块权重及验证集选模依据，原基线权重不覆盖。
- `baseline-test.jsonl`、`guided-test.jsonl`：两组完整原始回答。
- `results-comparison.json`、`experiment-report.md`：同次重跑基线与新模型的实测比较。
- `成果总结.md`：由完整实测结果自动填入的正式成果文案，CPU/smoke 结果不能触发正式回填。

原基线已存档数据：TICR **90.21%**，图像准确率 **88.97%**，文本准确率 **92.32%**，共同正确率 **85.75%**。
原始分析报告：`results/reference/moralclip-llava-polarity-20261104/analysis.md`。
正式比较以本次相同环境下重跑的基线为准；历史测试集已被多次使用，不称为新盲测。

## 2026-11-08 GPU 实测结果

A800 80GB 上已完成上述 3 轮训练与完整生成评测，新增模块训练共 1839 次优化更新。
正式训练及主评测耗时 48.24 分钟，固定终轮补充评测耗时 3.55 分钟；峰值已分配显存 15.18 GiB。
133 项完整回归检查通过，原视觉塔 199 个张量冻结校验通过，文本分支 288 条回答与同次基线逐字相同。

| 模型 | TICR | 图像准确率 | 图文共同正确率 |
|---|---:|---:|---:|
| 同次重跑原基线 | 90.20% | 88.96% | 85.74% |
| 验证选中 epoch 0 | 90.20% | 88.96% | 85.74% |
| 实际训练终轮 epoch 3（补充） | 89.84% | 88.61% | 85.38% |

三轮验证均未通过基线图像准确率守卫，选模保留零初始化残差。
训练终轮单独按提前锁定的计划评测，未用于重新选模；TICR 差值为 -0.36 个百分点，
场景配对 bootstrap 95% 区间为 [-5.13, +3.51] 个百分点，未证明改善。
固定训练图像更换道德维度问题后，视觉特征平均绝对差为 0.00134001，确认条件路径实际影响特征。
