- 最佳权重：`runs/moral-llava-1.5`，验证 loss 选择 checkpoint-804。
- 126 条图像预测已从 raw_prediction 复算，与保存指标一致。

| 方法 | 合规率 | Micro-F1 | 完全匹配率 |
| --- | ---: | ---: | ---: |

原始模型的零分来自指定输出协议失败：65 条非法 JSON 转义，61 条字段/取值不合规；同时存在复述词表、数组和未作出极性选择等问题。因此零分不能解释为没有道德判断能力。LoRA 提升同时包含格式学习与标签识别变化。

### 新版双路检索

- 图像：冻结 CLIP ViT-B/16 → 新投影器 → patch 池化 → 512 维图像头。
- 文本：Vicuna+LoRA → token 池化 → 512 维文本头。
- 图像特征参与检索损失，但正式训练中没有进入 Vicuna decoder。
- λ=0 与 0.4 均完成 10 epochs、330 updates，以验证道德 MAP 选 checkpoint。

| λ | 同图配对 R@1 | 道德 MAP | 排除本图的道德 MAP | 道德 R@10（原 Hit@10） |
| --- | ---: | ---: | ---: | ---: |

λ=0 是训练后的检索模型，不是原始 LLaVA。道德 R@10（原 Hit@10）表示前十条至少命中一条共享标签描述，不是跨模态判断一致率；两个 λ 条件也不是两个测试组。

另有 λ=0.05/0.1/0.2 训练；0.05 有独立测试文件，但扫描状态尚未同步。新版两个数据/训练源码文件与历史 manifest 哈希不同，核心模型、损失及评测代码相符。正式检索测试未保存全部逐条排序，只有汇总指标及查询/候选 ID，不能仅靠现有文件独立复算排序。

## 首轮成对评测目标（历史阶段，已完成）

首轮复用旧版 LoRA、不重训，建立原始基模与 LoRA、图像与文本的 2×2 对照；之后用户授权联合训练以提升一致性，见本文开头最新进展。

1. 将 126 个测试场景预先固定为互不重叠的 A/B 两组，每组 63 个，按完整标签组合平衡、固定 seed 42；每个场景固定原始第 0 条生成描述。分组不依赖预测结果。
2. 主指标为严格五维一致率：两种输入均有效且五维完全相同的场景数 / 全部场景数。阶段阈值为 60%，每组至少 38/63 才达标。
3. 补报逐维一致率、有效输出率、两模态各自准确率/F1、两边同时正确率、Wilson 95% 区间。
4. 条件保持率单独报告：基模已一致的场景中 LoRA 仍一致的比例。若基模无有效一致场景，报告未定义（null），不能记 0 或 100%。主验收不使用这个不稳定分母。
5. 自由生成与统一 JSON 约束生成分开报告。约束只限制合法格式和 243 种标签组合，不读取真值；不修补原始回答，不在看到结果后更换主指标、分组或描述。
6. not_annotated 表示数据未标注，不等于道德中性。描述继承图片标签，其语义等价性尚待人工审核；当前为现有数据上的探索性评测。

## 首轮成对实测结果（联合训练前）

主分析：两个模型均采用同一合法 JSON token 约束；每组 63 个不重叠场景，严格五维完整一致率门槛为 >=60%（至少 38/63）。

| 组 | 模型 | 五维完整一致率 | 逐维一致率 | 两种输入均正确率 |
| --- | --- | ---: | ---: | ---: |
| A | 原始基模 | 100.00% | 100.00% | 31.75% |
| A | 旧版 LoRA | 57.14%（36/63） | 76.51% | 46.03% |
| B | 原始基模 | 100.00% | 100.00% | 30.16% |
| B | 旧版 LoRA | 57.14%（36/63） | 76.19% | 39.68% |

**当时旧 LoRA 未达到预先固定的严格 60% 门槛；每组差 2 个一致场景。** 逐维一致率超过 60%，但它是辅助指标，不能事后替换主指标宣布达标。后续联合训练的达标结果见本文开头。

基模的 100% 是退化结果：252/252 条约束输出均为全 not_annotated、non_moral=true，标签准确率仅相当于常量基线。不能据此声称其道德判断更强。

自由生成下：基模图像/文本输出有效率均为 0%；LoRA 均为 100%，且 LoRA 两种解码的 252 条结构化判断逐条一致。LoRA 图像完全匹配为 70/126，文本为 67/126；54 个场景两边均正确，18 个一致但错误。

54 个不一致场景已保存。149 处维度不一致中，136 处涉及 not_annotated 与已标注状态，13 处为正负极性翻转。首轮结束时建议审核描述、补文本监督及图文一致性目标。后续已完成联合训练；描述审核及独立泛化评测仍待补充，固定测试组和描述保留。
